# Room links

MazeMap share links for the rooms this unit uses, kept here so other units can
reuse them rather than hunting for pins. These are the short `link.mazemap.com`
form, which resolves to the right room without needing the campus-collection
URL or an access token.

| **QB 1.59** | Design Suite — mechanisms sessions | <https://link.mazemap.com/o5Xo8oWt> |
| **PLT** | Pugsley Lecture Theatre (1.40) | <https://link.mazemap.com/KkMVJJVS> |

To get a link for another room: open [MazeMap](https://use.mazemap.com), find
the room, and use its share button. The public search API does not index these
rooms, so a link has to come from the app.
